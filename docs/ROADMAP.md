#### Milestone 8A：画像なしで成立するアイテム基盤

目的：専用画像を一枚も用意しなくても、初期アイテムを見たり、名前とカテゴリだけで新しいアイテムを登録したりできるようにする。

実装する：

- 下部ナビゲーションの「アイテム」画面

- ローカルまたはインラインSVGのアイコンレジストリ
- 未知の `iconKey` を `category` へ戻す安全なフォールバック
- カテゴリから `iconKey` と `genericVisualKey` を自動選択する純粋関数
- 画像を要求しないアイテムデータ型
- 六つの初期アイテム
- アイコン、名前、カテゴリを表示する一覧
- 拡大アイコンを必ず表示する詳細
- 名前とカテゴリだけで使えるかんたん登録
- 任意の短い説明
- `crypto.randomUUID()` または `crypto.getRandomValues()` によるアイテムID
- 登録確認後だけ行う保存
- IndexedDBバージョン5
- `items` ストア
- 起動時復元
- 壊れたアイテムだけを無視する部分復旧
- 初期アイテム未保存時の安全な作成
- 320px幅、44pxタップ領域、入力文字16px以上、読み上げ対応
- 純粋関数と保存復元を中心とした自動テスト

## 試遊で確認した将来の調整候補

- 「知らない芽」のパートナー相談が開花後だけにあるため、観察済みまたは成長前に相談し、育て方や結果へ関われる流れも再検討する。
- この候補は現在のアイテム実装へ混ぜない。イベント拡張の設計を見直す時に扱う。
- キャラクターピンを地点間の決められた経路に沿って連続補間し、つつーっと移動する演出を将来のビジュアル調整で検討する。

## Milestoneの進め方

1. 一度に扱うPRは一つ
2. 最新mainからブランチを作る
3. 対象Milestoneだけを実装
4. typecheck、test、buildを実行
5. 仕様対応を確認
6. 合格後にマージ
7. 次のMilestoneへ進む

## 素材制作の開始時期

仮素材でMilestone 2から4までの動作確認は完了した。

本番素材は、機能実装と同じPRへ混ぜず、マップの見える範囲、ピンの大きさ、接地点、吹き出し位置、代理位置、アイテム表示サイズを確認しながら別タスクで進める。

すべてのアイテムに個別画像を用意しない。

タイトルロゴ、表情大量差分、季節背景などはゲーム本体安定後に作る。
