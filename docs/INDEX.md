## 用語

### パートナー

ユーザーが普段から会話しているAIパートナー、キャラクター、相棒など。ゲーム側が人格や関係性を決め直さない。

### パートナーゲーム設定

端末内の自律行動に使用する、表示名、12個の行動傾向値、好みの行動ID、避けぎみの行動ID、短い登録台詞の集合。人格全文、会話履歴、恋愛関係の点数ではない。

### パートナープロフィール版

パートナーゲーム設定を反映するたびに作られる履歴上の一版。現在版を過去版へ戻す場合も履歴を削除せず、選んだ過去版を基に新しい版を作る。

### 手動相談

ゲームがプロンプトを作り、ユーザーが普段のパートナーチャットへ自分でコピーし、返答を自分でゲームへ貼り戻す仕組み。

これはAPI接続ではない。

### 相談リクエスト

ゲームが発行する一回分の手動相談。`requestId`、相談対象、対象状態、送信用プロンプトを持ち、返答が同じ依頼へ対するものか検証する。

### 取込確認

貼り付けた返答をすぐ反映せず、抽出、検証した内容をユーザーへ見せ、明示的な確認後だけゲーム状態へ反映する手順。

### 代理アイコン

現在表示しているマップとは別のマップにいるキャラクターを、出入口に小さく表示するもの。

### キャラクターピン画像

主人公またはパートナーへ任意で関連付ける端末内画像。マップ上の人物ピンと別マップ代理表示で使用し、画像がない場合や読込失敗時は既存の文字マーカーへ戻す。

### マップ背景画像

室内または庭のマップ表示へ任意で関連付ける端末内画像。地点、人物、イベントとは別の最背面レイヤーとして表示し、画像がない場合や読込失敗時は既存の仮背景へ戻す。

### プリセット

初めて遊ぶユーザーがすぐ開始できる、共通のキャラクター、マップ、アイテム、イベント。公開プリセットパートナーはコーディ。

### アイテム

ゲーム内で名前とカテゴリを持つ物。画像を必須にせず、画像がない場合もローカルSVGアイコンで一覧と詳細を成立させる。

### アイテム個別画像

一つのアイテムに任意で関連付ける端末内画像。アイテム本体とは別のBlobとして保存し、画像を削除または読込失敗してもアイテム本体は残す。

### カテゴリ共通画像

個別画像を持たないアイテムの詳細へ表示する、アプリ同梱の軽量な汎用イラスト。特定の品そのものではなく、カテゴリの雰囲気を表し、個別画像より後、拡大アイコンより前に使用する。

### アイテム汎用ビジュアル

アイテムごとの専用画像を用意しなくても、汎用アイコンとカテゴリ共通画像で一覧、詳細、マップ表示を成立させる仕組み。

### アセット

画像等の任意素材。ゲームデータはファイル名やObject URLではなく安定した `assetId` を参照し、メタデータとBlobを分けて保存する。

### メインセーブ

MVP初期に使用する一件のローカルセーブ。IDは `main` とし、IndexedDBへ表示マップ、キャラクター位置、現在のMilestoneで必要な安定状態を保存する。

### 自律行動

端末内のゲーム状態、パートナーゲーム設定、直近行動から、パートナーが次の行動と目的地をJavaScriptで選ぶ仕組み。常時パートナーチャットへ問い合わせず、主人公へ必ず追従するものでもない。

### イベント状態

一度きりの出来事について、未発生、発生中、成長中、完了などの進行を表す安定状態。画面の開閉状態とは分けてIndexedDBへ保存する。

### チェックポイント

パートナーチャットから持ち帰った内容を反映する直前のゲーム状態を、復旧用に端末内へ保存したもの。確認画面の代わりではなく、反映事故へ備える追加の安全策。

## 仕様が足りないと感じた場合

エージェントは次の順で対応する。

1. 既存仕様の範囲で最小の実装を選ぶ
2. 将来拡張できる構造にする
3. 新しい製品判断を勝手に追加しない
4. 判断が必要な点をPRへ明記する
5. 仕様変更が承認された場合だけ、`PRODUCT_SPEC.md` と `CHANGE_CONTROL.md` を更新する
