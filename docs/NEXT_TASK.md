# 次の実装タスク

この文書には、Codexへ渡す依頼文を何度も読み返さずに済むよう、現在実装する一件だけを記載する。

作業開始前に `AGENTS.md`、`docs/INDEX.md`、`docs/PRODUCT_SPEC.md`、`docs/ITEM_VISUALS.md`、`docs/ROADMAP.md` を読むこと。

## 対象

Milestone 8B-4B：出入口接続と代理位置

## 目的

室内 `starter_house_interior` と庭 `starter_garden` に現在ある地点から一件ずつを出入口として選び、必ず往復できる一組のマップ間接続として保存できるようにする。

同時に、別マップにいる人物を示す代理アイコンの位置を表示中マップごとに調整し、庭の家の外観ボタンも登録背景へ合わせて配置できるようにする。

このMilestoneでは、Milestone 8B-4Aで保存できるようにした地点配置を利用する。地点ID、地点名、地点タイプ、各マップ内の隣接関係は維持し、マップ間の出入口と表示上の入口だけを設定する。

プリセット初期値：

- 室内出入口：`starter_house_interior / entrance`
- 庭出入口：`starter_garden / front_of_house`
- 室内の代理位置：有効な室内出入口地点の表示座標
- 庭の代理位置：有効な庭出入口地点の表示座標
- 庭の家の外観位置：現在の家の外観ボタンの見た目を維持する固定初期座標

正確な既存locationIdはコード上の定義を優先する。新しい地点IDを作らない。

## このMilestoneで変えないもの

- マップID、マップ種別、地点ID、地点名、地点タイプを変更しない
- 地点を追加、削除、複製、改名しない
- 各マップ内の `connectedLocationIds` と既存の隣接関係を変更しない
- 移動速度、移動中継点、自由歩行を追加しない
- Milestone 8B-4Aの地点配置UI、地点座標、背景画像を変更しない
- キャラクターピンの接地点、表示倍率、画像内表示位置を変更しない
- 人物の現在地を設定編集だけで変更しない
- 家の外観ボタンをキャラクター移動操作へ変更しない。従来どおり表示マップを室内へ切り替える操作とする
- 代理アイコンのラベル、人物画像、文字マーカーフォールバック、居場所ダイアログを変更しない
- アイテムスロット、アイテム配置を追加しない
- 新しいマップの作成、複製、削除を追加しない
- 背景画像、人物画像、アイテム画像の追加、変更、削除を変更しない
- 画像Blobを加工しない
- IndexedDBバージョンを8へ上げない
- 新しいストア、外部依存、外部通信、APIを追加しない

基本アイテムスロットはMilestone 8B-4Cへ、新しいカスタムマップ作成はMilestone 8B-4Dへ分ける。人物ピンの直接タッチ調整と地点間の中継点動線は、`docs/ROADMAP.md` の将来候補のままとし、このMilestoneへ混ぜない。

## 1. 安定データ

既存 `mapVisuals` ストアと `MapVisualState` または同等のマップ別安定データへ、後方互換な出入口・表示設定を追加する。

少なくとも次の意味を持つ構造とする。

```ts
type RelativePoint = {
  x: number;
  y: number;
};

type MapGatewayVisual = {
  gatewayLocationId: string;
  proxyPosition: RelativePoint;
  entryAffordancePosition: RelativePoint | null;
};
```

正確な型名とファイル分割は既存構造へ合わせてよい。

意味：

- `gatewayLocationId`：そのマップで他方のマップへ接続する既存地点ID
- `proxyPosition`：別マップ人物の代理アイコンを表示する相対座標
- `entryAffordancePosition`：地点とは別に表示する入口UIの相対座標
- 室内には独立した入口UIがないため、室内の `entryAffordancePosition` は `null` または同等の未使用値とする
- 庭では `entryAffordancePosition` を家の外観ボタンへ使用する

保存方法は次を満たすこと。

- 室内レコードと庭レコードが、それぞれ自分の `gatewayLocationId` と `proxyPosition` を持つ
- 庭レコードだけが家の外観位置を持つか、同等の後方互換な構造を使う
- 出入口の接続先は、二つの有効な `gatewayLocationId` から実行時に双方向へ解決する
- CSS文字列、ピクセル値、DOM座標、Object URLを安定データへ保存しない
- 一時ドラフト、選択中タブ、フォーカス状態を保存しない

## 2. 出入口接続の検証と復旧

室内と庭の出入口は、必ず一組として検証する。

有効条件：

- 室内側IDが室内マップに実在する
- 庭側IDが庭マップに実在する
- 片方の地点から庭、もう片方の地点から室内へ必ず戻れる双方向接続として解決できる
- マップ内の既存 `connectedLocationIds` は変更しない

復旧ルール：

- 室内側または庭側のどちらか一方でも不明、空文字、型不正なら、出入口IDの組だけをプリセットの `entrance` と `front_of_house` へ戻す
- 有効な代理位置、家の外観位置、背景参照、地点配置は、出入口IDの不具合だけを理由に捨てない
- 既存DB7レコードに出入口設定がなければプリセット接続を補う
- プリセットマップ定義そのものを実行中に書き換えない

純粋関数として少なくとも次を分離する。

- 二つのマップ別保存値から有効な出入口ペアを復元する
- 有効な出入口ペアを、地点配置適用後の一時的なMapDefinition相当へ双方向に重ねる
- 既存のgateway指定を一度安全に取り除き、選択された二地点だけへ新しい相互接続を付与する
- 共有プリセット定義と `connectedLocationIds` を破壊しない

## 3. 表示座標の検証と復旧

`proxyPosition` と庭の `entryAffordancePosition` は0から1の有限数で保存する。

- 左端0、右端1
- 上端0、下端1
- 基本刻み0.01
- 永続化前に小数第2位相当へ正規化してよい
- `NaN`、`Infinity`、文字列、範囲外は受理しない
- `x`、`y`の片方だけ不正なら、その成分だけ安全な初期値へ戻す

編集UIから保存できる代理アイコン中心座標は原則0.05から0.95とする。

庭の家の外観ボタンは代理アイコンより大きいため、320px幅でも著しく枠外へはみ出さない安全な範囲を固定する。現在の見た目を初期値として定数化し、実行時のDOM測定値を保存しない。

代理位置が欠損または不正な場合は、対応マップの有効な出入口地点へMilestone 8B-4Aの地点配置を適用した座標へ戻す。

庭の家の外観位置が欠損または不正な場合は、現在の家の外観表示を維持する固定初期座標へ戻す。

## 4. 設定画面

既存「設定」画面の「マップ背景」付近へ、室内と庭をまとめて扱う `出入口と代理表示` または同等の編集操作を追加する。

出入口接続は二枚一組なので、室内と庭を別々に保存するUIにしない。

### 4.1 編集開始

編集開始時は、現在の有効な出入口ペア、代理位置、庭の家の外観位置を一時ドラフトへコピーする。

- 編集開始だけでは永続状態、実際のマップ、人物現在地を変更しない
- 背景画像または地点配置の選択中、保存中、削除確認中は開始しない
- 出入口編集中は背景変更、地点配置編集、人物表示調整を同時に開始しない
- 自律行動などの無関係なStore更新でドラフトと選択状態を失わない

### 4.2 プレビュー

iPhone縦画面では、室内と庭の3:4プレビューをタブ、切替ボタン、または縦積みで確認できるようにする。横並びを必須にしない。

各プレビューへ次を表示する。

- 現在の背景画像または仮背景
- Milestone 8B-4Aの保存済み地点配置
- 選択中の出入口地点
- 代理アイコン位置の読み取り専用ダミー表示
- 庭では家の外観ボタン位置の読み取り専用ダミー表示
- 地点名と現在座標

プレビュー上の地点、代理ダミー、家ダミーを操作しても、人物移動、マップ切替、居場所ダイアログを実行しない。

### 4.3 操作

少なくとも次を提供する。

- 室内の既存地点から出入口を一件選ぶ
- 庭の既存地点から出入口を一件選ぶ
- 各マップの代理位置の横、縦range入力
- 庭の家の外観位置の横、縦range入力
- 現在値の百分率表示
- `プリセットの玄関と家の前へ戻す`
- `代理位置を出入口地点へ戻す`
- `家の外観位置を初期値へ戻す`
- `この接続と配置を保存`
- `キャンセル`

マーカーや代理ダミーをドラッグできるようにしてよいが、ドラッグだけを必須にしない。出入口地点の選択と座標rangeはキーボードとタッチの両方で操作できること。

一つの値を変えても、他方のマップ、他の座標成分、地点配置ドラフトを上書きしない。

### 4.4 保存とキャンセル

- 保存前はプレビューだけを更新する
- 保存成功後だけStoreの安定状態と実際の経路、代理表示、家の外観へ反映する
- 保存失敗時は旧接続と旧表示位置を維持し、ドラフトを残す
- キャンセル時は保存済み設定へ戻る
- 初期値へ戻す操作もドラフトだけを更新し、保存操作で確定する
- 保存中は二重操作を無効化する
- 成功、失敗を `aria-live` で通知する

## 5. 永続化

IndexedDBバージョン7と既存 `mapVisuals` ストアを維持する。

出入口ペアは片側だけ更新すると不整合になるため、室内と庭の二レコードを一つの `readwrite` transactionで更新する。

- 新しいストアを追加しない
- 二つの `backgroundAssetId` を維持する
- 二つの `locationLayout` を維持する
- 既存の更新時刻方針へ合わせて両レコードを更新する
- transaction成功後だけ二レコードをメモリ状態へ反映する
- transaction失敗時は両方の旧レコードを維持する
- 通常の全体保存、起動時復元、Safariの履歴復元で設定を失わない
- 一時ドラフトをSaveSnapshotまたは安定レコードへ含めない

RepositoryまたはSaveCoordinatorに、出入口ペアと表示位置をまとめて保存する専用処理を追加してよい。片方ずつ公開する保存処理は、この編集フローから使用しない。

全体リセットではプリセット出入口、代理位置、家の外観位置へ戻す。背景画像、地点配置、人物画像、人物ピン設定、アイテム画像に関する既存リセット仕様を維持する。

## 6. マップ定義と経路探索

実際の移動、最短経路、自律行動、代理人物判定では、次の順に解決した一時的なマップ定義を使用する。

1. 共有プリセットマップ定義
2. Milestone 8B-4Aの保存済み地点配置
3. Milestone 8B-4Bの有効な出入口ペア

有効な出入口ペアを反映する時は、二つの選択地点へ次を付与する。

- 室内側の選択地点から、庭側の選択地点へのgateway
- 庭側の選択地点から、室内側の選択地点へのgateway

他の地点にはマップ間gatewayを残さない。

維持するもの：

- マップ内の地点ID列
- 地点名と地点タイプ
- `connectedLocationIds`
- 主人公の地点選択移動
- パートナーの自律移動
- 同一マップ内の最短経路
- マップをまたぐ最短経路
- 移動中の段階的地点更新
- 論理現在地の `mapId` と `locationId`

出入口を変更した後は、主人公とパートナーの次回移動から新しい接続を使う。設定保存だけで現在地を強制移動しない。

現在地が旧出入口地点にあっても有効な通常地点として残す。地点そのものは削除しない。

## 7. 代理アイコン

別マップにいる人物の判定は、人物の実際の `mapId` を使用する。

- 表示中マップと異なるマップにいる人物だけを代理表示する
- 代理アイコンは表示中マップの保存済み `proxyPosition` へ表示する
- 代理位置は出入口地点とは独立してよい
- 複数人物を将来扱える現在のまとめ表示構造を維持する
- 主人公とパートナーの画像内表示位置を維持する
- 画像なし、欠損、読込失敗時は文字マーカーへ戻す
- ボタンサイズ、44px以上の操作領域、ラベル、居場所ダイアログを維持する
- 代理アイコンのタップで人物現在地を変更しない

代理位置が不正な場合だけ、有効な出入口地点の表示座標へ戻す。

## 8. 庭の家の外観

庭マップの家の外観ボタンを、保存済み `entryAffordancePosition` または同等の安全な相対座標へ表示する。

- 背景、地点、イベント、人物、代理表示との既存レイヤー順を維持する
- 現在の見た目、屋根、文言、aria-labelを維持する
- タップ時は従来どおり表示マップを室内へ切り替える
- タップだけで主人公またはパートナーを室内へ移動しない
- 室内マップへ同種の家ボタンを新設しない
- 位置が不正な場合は固定初期座標へ戻す

## 9. アクセシビリティとモバイル

- iPhone Safariの縦画面を最優先する
- 320px幅で横スクロールを発生させない
- 主要操作、地点選択、プレビュー切替は44px以上
- range入力と入力周辺の文字は16px以上
- 選択中の出入口、代理位置、家位置を色だけで示さない
- 地点名と現在値をテキストで確認できる
- キーボードとタッチの両方で操作できる
- フォーカス表示を消さない
- プレビュー更新で不要なフォーカス移動を起こさない
- `prefers-reduced-motion` を維持する

## 10. セキュリティとプライバシー

- 外部通信を追加しない
- 出入口、代理位置、背景、人物現在地をパートナーチャットや相談プロンプトへ追加しない
- 動的な地点名と数値は `textContent` または安全なDOM APIで描画する
- 保存値を検証せずCSSへ渡さない
- `innerHTML`、`eval`、`Function`、動的importを使用しない

## 11. このMilestoneで扱わないもの

- 地点の追加、削除、改名、複製、種類変更
- マップ内経路、隣接関係、移動速度の編集
- 地点間の中継点、折れ線動線、自由歩行
- 人物ピン画像のドラッグ、ピンチ調整
- 家の外観画像の差し替え
- 代理表示専用の人物画像、倍率、切抜き設定
- アイテムスロットとアイテム配置
- 新しいカスタムマップの作成、複製、削除
- 背景画像の加工、倍率、表示位置
- 思い出、バックアップ、PWA
- 本番素材制作

1. 既存セーブで起動し、背景、地点配置、人物画像、人物ピン設定が残っていることを確認する。
2. 「設定」から「出入口と代理表示」を開く。
