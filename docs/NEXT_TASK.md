# 次の実装タスク

この文書は、Codexへ長い依頼文を毎回貼らずに済むよう、次の一件だけを記載する。

作業開始前に `AGENTS.md`、`docs/INDEX.md`、`docs/PRODUCT_SPEC.md`、`docs/ROADMAP.md` を読むこと。

## 対象

Milestone 1.1：移動実装前の補修

## 目的

Milestone 2でキャラクター移動を実装する前に、マップ比率、キャラクター位置、文字描画、検証環境を整える。

## 実装する

1. マップ領域を縦長3:4へ変更する。
2. 主人公とコーディの状態に `mapId` と `locationId` を持たせる。
3. キャラクターピンを、地点データの座標から描画する。
4. 表示中マップと異なるマップにいるキャラクターを、代理表示対象として純粋関数で求める。
5. 動的な文字列を `innerHTML` へ挿入せず、安全なDOM生成へ変更する。
6. ダイアログを閉じた後、開いた操作元へフォーカスを戻す。
7. GitHub Actionsを追加し、typecheck、test、buildを実行する。
8. 上記の状態・セレクターに自動テストを追加する。

## 実装しない

- 主人公またはコーディの移動
- IndexedDB
- 自律行動
- イベント
- パートナーチャットへの手動相談
- 画像登録
- アイテム画面
- PWA
- GitHub Pages
- 本番素材

## 完成条件

- 320px幅で横スクロールしない
- マップが3:4
- UとCが地点データの位置へ表示される
- 代理表示がキャラクター状態から求められる
- 動的文字列が安全に描画される
- ダイアログ終了後にフォーカスが戻る
- typecheck、test、buildが成功する
- 既存の室内・庭切り替え、ナビゲーション、開発者パネルが維持される
