# 将来候補：通常マップ上での直接アイテム配置

この文書は将来候補の設計メモです。現在の `docs/NEXT_TASK.md` と進行中のMilestoneへ自動的に追加しません。実装時に独立した詳細仕様を作り、保存形式、入力競合、アクセシビリティ、既存データへの影響を改めて固定します。

## 目的

設定画面で座標スライダーだけを使うのではなく、普段見ている室内・庭のマップ上で、背景や地点との位置関係を確認しながらアイテムを直感的に配置できるようにする。

## 操作候補

- 通常マップに明示的な「配置編集モード」を用意し、通常の移動、イベント、アイテム詳細操作と競合させない
- 所持品からマップへドラッグ＆ドロップして配置する
- 配置済みアイテムを一本指でドラッグし、表示位置を調整する
- iPhoneでは長押し、ページスクロール、ブラウザのコンテキスト操作との競合を避ける
- タッチ操作だけを必須にせず、現在のスロット選択、range入力、明示保存、キャンセルを代替手段として残す
- 主要なタップ領域を44px以上に保ち、選択状態を色だけで示さない

## 引き継ぐ安全ルール

- 保存前は編集ドラフトだけを変更する
- 保存成功後だけ通常マップへ反映する
- 保存失敗時は以前の配置を維持し、ドラフトを残す
- 一つのアイテムは同時に一ヶ所までとする
- 配置してもアイテム本体は所持品へ残す
- 配置編集だけで人物を移動させず、イベントや自律行動を発生させない
- 背景、地点、出入口、代理表示、人物ピンの既存操作を壊さない

## 段階分け

最初は現在の固定六スロットをマップ上で直接動かす操作として実装できる。固定枠を越える自由配置、回転、倍率、重なり順、個別画像表示は別段階とし、一度に混ぜない。
